# Compare Tires Page
The Compare Tires Page allows users to view detailed information side by side for up to four selected tires. It is designed to help users make informed purchasing decisions by highlighting differences in specifications, features and pricing

#### Scenario 1: Viewing comparison of 2 tires
**Condition**: User has added 2 tires to the compare tray on the Products Listing Page.

**Steps**:
- User selects 2 tires for comparison on the Products Listing Page.
- User clicks the Compare button.

**Expected Outcome**:
- User is redirected to the Compare Tires Page.
- Both selected tires are displayed side by side.
- Comparison includes key specs (size, speed rating, tread type) and pricing.

#### Scenario 2: Removing all tires from comparison
**Condition**: User is on the Compare Tires Page with tires selected for comparison.

**Steps**:
- User clicks Remove on all tires in the comparison table.

**Expected Outcome**:
- All tires are removed from the comparison table.
- Since no tires remain for comparison, user is automatically redirected to the Products Listing Page.
- Compare tray is now empty.
