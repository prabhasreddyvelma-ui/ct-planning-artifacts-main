# Size Selection Page
On this page, users select the front and rear tire sizes for their vehicle based on the search criteria (License Plate or Vehicle).

Users must verify the tire size by checking a confirmation box, acknowledging that they have confirmed the specifications on their vehicle's placard. This ensures users understand the importance of selecting the correct tire size and helps prevent errors.

The page also includes a **Tire Size Guide** link to assist users in selecting the correct tire size.

#### Scenario 1: User clicks the Tire Size Guide link
- Opens a drawer from the right with instructions on locating tire size information, including examples of tire size formats and where to find this information on the tire, in the vehicle manual, or on the placard.

#### Scenario 2: User selects a tire size but does not verify the placard
- Displays an error message prompting the user to verify the specifications on the placard before proceeding.

#### Scenario 3: User selects a tire size and verifies the placard
- Allows the user to proceed to the **Product Listing Page**.
