# Product Details Page
On this page, users can view comprehensive information about a specific tire to make informed purchase decisions. The page provides detailed specifications, product features and pricing.

## Tire Information Card

- Shows key specifications, including feature badges (e.g., Original Equipment, Run Flat, EV Compatible), brand logo, tire name, tire size, load index, speed rating, season, warranty mileage, EV readiness, and run-flat capability.
- Includes a share icon—clicking it opens a dropdown menu with options to share via Facebook, Twitter, or email.

## Tires Pricing Card
- Displays all the pricing details like online price, discounts, and additional fees.

## Tires Fulfillment Card
- Shows selected tire center name (not editable).
- Pickup box: displays estimated pickup date and shipping charges.
- Out-of-stock items: Pickup box crossed out with Item Unavailable note below.

## Quantity & Cart Card
- Allows user to select quantity and Add to Cart.
- Out-of-stock items:
  - Quantity selector hidden
  - Add to Cart button replaced with disabled Item Unavailable button
  - Red box above button displays: "This item is currently unavailable. Please try again later."

## Product Information (Accordion)
The product page also features an accordion layout to organize detailed information under collapsible sections.

#### Scenario 1: User shares product on Facebook from the Tire Information
- User clicks the Share icon on the Tire Information Card.
- A dropdown menu appears with options: Facebook, Twitter, Email.
- User selects Facebook.
- A new window opens with the Facebook share dialog pre-populated with the tire product information (name, image, link).
- User can edit the post and click Share to publish it on their Facebook timeline.

#### Scenario 2: Zoom functionality
- User clicks the Zoom icon on an image.
- A modal opens as a placeholder for future zoom functionality.

#### Scenario 3: Viewing product specs
- User reviews specifications like tire size, season, speed rating, load index, EV readiness, and run-flat capability.
- Share link allows sharing via Facebook, Twitter, or email.

#### Scenario 5: Viewing pricing details
- User sees online price, discounts, and additional fees (installation or delivery).

#### Scenario 6: Viewing tire fulfillment details
- User sees selected tire center name, estimated pickup date, and shipping charges.
- If the tire is out of stock, Pickup box is crossed out with Item Unavailable displayed.

#### Scenario 7: Adding in-stock product to cart
- User selects quantity and clicks Add to Cart.
- Product is added to the cart and Added to Cart Drawer opens automatically.

#### Scenario 8: Interacting with out-of-stock product
- Quantity selector is hidden.
- Add to Cart button replaced with disabled Item Unavailable button.
- Red box above the button shows: "This item is currently unavailable. Please try again later."
