# Overview
Build a **production-ready, responsive Next.js application** using designs from the /Designs folder and Webpack (instead of Turbopack), optimized for performance, scalable, secure, and utilizing **Redux** for state management. Follow industry best practices, including modular architecture, server-side rendering (SSR) where appropriate, and accessibility compliance.

# Technical Stack
- **Framework:** Next.js (latest stable version)
- **Build Tool:** **Webpack** (built-in with Next.js, customized via next.config.js if needed)
- **Styling:** SCSS, Bootstrap 5
- **State Management:** Redux Toolkit
- **Routing:** Next.js pages and dynamic routes
- **API Integration:** REST API
- **Map Integration:** Bing Maps API for tire center selection
- **Performance:** Image optimization, code-splitting, lazy loading (leveraging Next.js + Webpack optimizations)
- **Security:** Authentication, HTTPS, input validation, secure headers
- **Testing:** Jest + React Testing Library
- **Linting & Formatting:** ESLint, Prettier

**Note**: Use Designs present in the docs/design folder.
